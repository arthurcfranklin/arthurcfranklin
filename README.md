### About

I work in IT support and infrastructure, with hands-on experience in user support, troubleshooting, monitoring, virtualization, networking, and operational documentation.

My day-to-day work involves Windows and Linux environments, infrastructure monitoring with Zabbix, Grafana and The Dude, virtualization with Proxmox VE, incident analysis, and support for systems and network services.

Alongside infrastructure operations, I develop tools and automation with Python and web technologies to reduce repetitive work, organize technical processes, and solve practical problems found in IT environments.

My current focus is progressing toward infrastructure and advanced technical support roles while strengthening my knowledge of Linux administration, monitoring, networking, virtualization, and automation.
